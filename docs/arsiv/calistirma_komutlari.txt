───────────────────────────────────────────────────────────────────────────────
 5) MOBİL (Flutter)                        (4. terminal)
───────────────────────────────────────────────────────────────────────────────
 ⭐ ÖNERİLEN — tüneli de kuran başlatıcı:

    cd C:\Projects\misc\ghidra\mw\apps\mobile
    .\tool\dev.ps1

  Betik sırayla: adb'yi bulur → bağlı cihazı seçer → `adb reverse` tünelini
  kurar → /healthz'i yoklar → `flutter run --debug` koşar.
  Birden fazla cihaz varsa:   .\tool\dev.ps1 -Device R6CW500FM4M

 ─ ELLE yapmak gerekirse (üç adım, SIRASI önemli) ─────────────────────────────

    adb devices                          # cihaz "device" durumunda mı
    adb reverse tcp:3002 tcp:3002        # ⚠️ ASIL ADIM — bunsuz bağlanamaz
    flutter run --debug

  Tünel kuruldu mu:   adb reverse --list   → "tcp:3002 tcp:3002" görünmeli

 ⚠️⚠️ "flutter run çalıştı ama API'ye bağlanamıyor" arızasının SEBEBİ HEP BU:
    Uygulama geliştirmede http://127.0.0.1:3002'ye bakar; telefonda oradaki
    dinleyici `adb reverse` tünelidir. Tünel KALICI DEĞİL, şu üç durumda düşer:
       • USB kablosu çıkıp takılınca
       • `flutter install` / `flutter run` kurulum adımında
       • telefon yeniden başlayınca
    Düştüğünde ekran "API çökmüş" gibi görünür, oysa API sapasağlamdır.
    Çözüm tek satır:  adb reverse tcp:3002 tcp:3002

 ⛔ `flutter run --release` KULLANMA: release APK yerel API'ye ASLA bağlanamaz
    (Android 9+ cleartext yasağı; izin yalnız debug manifestinde). Hata mesajı
    bunu söylemez, yalnız "Dünya listesi alınamadı" yazar.

 ⚠️ adb PATH'te yoksa bu makinedeki tam yol:
       C:\Android\Sdk\platform-tools\adb.exe
    (Android Studio varsayılanı olan %LOCALAPPDATA%\Android\Sdk DEĞİL.)
